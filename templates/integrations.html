Contractor Stripe checkout

{{ 'Test checkout configured' if stripe_readiness.ready and stripe_readiness.test_mode else 'Live checkout configured' if stripe_readiness.ready else 'Setup required — contractor purchases are unavailable' }}

This checks server configuration only. It does not verify your Stripe account or webhook delivery.

Contractors pay for leads at Payments and receipts. They do not connect their own Stripe accounts.

  1. Store a restricted Stripe API key in Railway’s protected STRIPE_SECRET_KEY variable. Grant the Checkout Session and related product/price permissions required by this integration. Test permissions in a sandbox first.
  2. Create a Stripe webhook destination for https://www.restorationcontractorsmn.com/webhooks/stripe. Subscribe to checkout.session.completed, checkout.session.async_payment_succeeded, checkout.session.async_payment_failed, checkout.session.expired and charge.refunded. Store its signing secret in STRIPE_WEBHOOK_SECRET.
  3. Set PUBLIC_SITE_URL=https://www.restorationcontractorsmn.com, STRIPE_MODE=test, PAYMENTS_ENABLED=true, CHECKOUT_RECONCILIATION_ENABLED=true and a timezone-aware PAYMENTS_ACTIVATION_UTC. Keep STRIPE_LIVE_PAYMENTS_ENABLED=false during testing.
  4. Verify signed confirmation, contact access, refunds and financial reports in test mode. Live checkout additionally requires live credentials, the live destination signing secret, STRIPE_MODE=live and STRIPE_LIVE_PAYMENTS_ENABLED=true.

Current authorized pricing evidence is also required before an offer can be purchased. Signing in to the Stripe Dashboard does not install these settings. Never enter API keys in contractor forms or chat.
